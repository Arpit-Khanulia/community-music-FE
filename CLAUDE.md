# Community Music Frontend

## Project Overview
- **Type**: React 19 + Vite SPA
- **Purpose**: Music downloader web interface
- **URL**: https://community-music-fe.vercel.app

## Tech Stack
- React 19
- Vite 8
- CSS (no Tailwind)

## Key Files
- `src/App.jsx` - Main component
- `src/App.css` - Styling
- `index.html` - Entry point
- `vite.config.js` - Vite config

## Environment Variables
- `VITE_API_URL` - Backend API URL (e.g., `https://backend.railway.app/api`)

## Commands
```bash
npm run dev    # Development
npm run build  # Production build
```

## Design
- Dark theme with amber accent (#f5a623)
- DM Sans + Sora fonts
- Minimal, sleek UI with noise texture overlay
